## Quick setup

Run the interactive setup wizard to generate your config:

```bash
npx playwright-manager init
```

Or configure manually as described below.

## Configure the Reporter

Add the reporter to your `playwright.config.ts`:

```ts title="playwright.config.ts"
export default defineConfig({
  reporter: [
    ["html"],
    ["@playwright-manager/reporter", {
      apiUrl: "http://localhost:3000",
      repository: "your-org/your-repo",
    }],
  ],
});
```

### Reporter options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `apiUrl` | `string` | `PLAYWRIGHT_MANAGER_URL` env var | Dashboard URL |
| `repository` | `string` | `PLAYWRIGHT_MANAGER_REPOSITORY` env var | Repository in `org/repo` format |
| `disabled` | `boolean` | `false` | Disable without removing config |
| `branch` | `string` | auto-detect | Override git branch |
| `commitSha` | `string` | auto-detect | Override commit SHA |
| `ciJobUrl` | `string` | auto-detect | Override CI job URL |
| `batchSize` | `number` | `50` | Results per API request |
| `flushInterval` | `number` | `5000` | Flush interval in ms |
| `failSilently` | `boolean` | `true` | Suppress API errors |
| `runId` | `string` | auto-generate | Custom run identifier |
| `debug` | `boolean` | `false` | Enable debug logging |
| `s3` | `object` | — | S3 config for HTML report hosting |

### S3 report hosting

To upload Playwright HTML reports to S3-compatible storage:

```ts title="playwright.config.ts"
["@playwright-manager/reporter", {
  apiUrl: "http://localhost:3000",
  repository: "your-org/your-repo",
  s3: {
    bucket: "playwright-reports",
    region: "us-east-1",
    // For MinIO, R2, or other S3-compatible providers:
    // endpoint: "http://localhost:9000",
    // accessKeyId: "minioadmin",
    // secretAccessKey: "minioadmin",
  },
}],
```

## Configure the Fixture

Add the fixture options under `use` in your `playwright.config.ts`:

```ts title="playwright.config.ts"
export default defineConfig({
  use: {
    testManager: {
      apiUrl: "http://localhost:3000",
      repository: "your-org/your-repo",
    },
  },
});
```

Then import `test` and `expect` from the fixture in your test files:

```ts title="tests/example.spec.ts"
import { test, expect } from "@playwright-manager/fixture";

test("my test", async ({ page }) => {
  await page.goto("https://example.com");
  await expect(page).toHaveTitle(/Example/);
});
```

### Fixture options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `apiUrl` | `string` | `PLAYWRIGHT_MANAGER_URL` env var | Dashboard URL |
| `repository` | `string` | `PLAYWRIGHT_MANAGER_REPOSITORY` env var | Repository in `org/repo` format |
| `disabled` | `boolean` | `false` | Skip quarantine checking |
| `cacheTtl` | `number` | `60000` | Cache TTL in ms |
| `failSilently` | `boolean` | `true` | Suppress API errors |
| `timeout` | `number` | `5000` | API request timeout in ms |
| `debug` | `boolean` | `false` | Enable debug logging |
| `branch` | `string` | auto-detect | Override git branch |

## Configure the ESLint Plugin

### Flat config (ESLint 9+)

```js title="eslint.config.js"
import playwrightManager from "@playwright-manager/eslint-plugin";

export default [
  ...playwrightManager.configs.recommended,
];
```

### Legacy config (ESLint 8)

```json title=".eslintrc.json"
{
  "plugins": ["@playwright-manager"],
  "rules": {
    "@playwright-manager/require-fixture-imports": "error"
  }
}
```

## Environment variables

Both the reporter and fixture support environment variable fallbacks. This is useful for org-wide CI configuration:

| Variable | Used by | Purpose |
|----------|---------|---------|
| `PLAYWRIGHT_MANAGER_URL` | Reporter, Fixture | Dashboard URL fallback |
| `PLAYWRIGHT_MANAGER_REPOSITORY` | Reporter, Fixture | Repository fallback |

Precedence: explicit config option > environment variable > empty (disabled).

### GitHub Actions example

```yaml title=".github/workflows/test.yml"
jobs:
  test:
    runs-on: ubuntu-latest
    env:
      PLAYWRIGHT_MANAGER_URL: https://playwright-manager.internal
      PLAYWRIGHT_MANAGER_REPOSITORY: your-org/your-repo
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npx playwright install --with-deps
      - run: npx playwright test
```

### GitLab CI example

```yaml title=".gitlab-ci.yml"
test:
  variables:
    PLAYWRIGHT_MANAGER_URL: https://playwright-manager.internal
    PLAYWRIGHT_MANAGER_REPOSITORY: your-org/your-repo
  script:
    - npm ci
    - npx playwright install --with-deps
    - npx playwright test
```

## Verify your setup

```bash
npx playwright-manager check-connection
```

This checks dashboard connectivity, database status, and storage configuration.
