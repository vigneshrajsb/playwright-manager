Playwright Manager helps you track test health, manage flaky tests, and control test execution remotely from a centralized dashboard.

## Features

- Health scoring and flakiness tracking
- Remote test quarantine with branch and environment patterns
- CI integration with auto-detection for GitHub Actions, GitLab CI, and more
- Self-hosted — your data stays on your infrastructure
